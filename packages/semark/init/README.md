# A corpus to start from

`patterns.md`, `words.md` and `roles.md` are the shared vocabulary; every folder with an `index.md` that says `sema: design` is a design.
The design `hello` is the smallest one that says something: one flow, two screens, one field, one action.

Run `semark check .` here; then rename `hello`, and add a `data.md` when the design has a record.
How to write a design is in the Semark repository's `spec/syntax.md`; the rules the checker enforces are in `spec/checks.md`.
